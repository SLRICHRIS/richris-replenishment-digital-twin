# Purpose of every repository file

Names identify the work each folder and source file performs. Browser code and Python services are separate. Generated downloads are built from canonical sources.

## Standard filenames retained

| File name | Why it keeps this name |
| --- | --- |
| `README.md` at the repository root | GitHub displays the project introduction automatically. |
| `streamlit_app.py` | Preserves the existing Streamlit Cloud main-file setting. |
| `requirements.txt` | Streamlit deployment discovers and installs this root dependency file. |
| `package.json`, `package-lock.json` | npm discovers commands and locked development dependencies by these names. |
| `.streamlit/config.toml` | Streamlit reads configuration from this fixed location. |
| `.gitignore` | Git reads exclusion rules from this filename. |
| `index.html` | Streamlit’s local component serves this browser entry document. |
| `__init__.py` | Python recognizes importable packages through these files. |
