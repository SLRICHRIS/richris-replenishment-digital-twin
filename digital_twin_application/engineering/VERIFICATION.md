The synthetic speed-bias fixture fits a gain of approximately 1.1199 against an injected 1.12 gain. Its held-out one-interval displacement RMSE decreases from approximately 0.01478 m to 0.00323 m. These figures demonstrate identification of that synthetic model only; they are not measured AMR localization accuracy.

The reference paired fixture produces different shortage outcomes under FIFO and earliest-stockout scheduling at a 120 s horizon and 5× demand. Longer horizons can erase that advantage when both policies face the same total supply deficit. No physical benefit is claimed from these synthetic comparisons.

The expanded layout was checked with `node automated_tests/shortest_path_optimality_checks.mjs`, `node automated_tests/warehouse_geometry_checks.mjs`, `node automated_tests/mission_approval_and_route_checks.mjs`, `node automated_tests/twin_calibration_and_replay_checks.mjs`, `node automated_tests/dashboard_interaction_checks.cjs` and the jsdom motion checks. Interactive navigation adds `node automated_tests/interactive_route_map_checks.mjs` and the jsdom `automated_tests/route_map_interaction_checks.cjs`. The route test also confirms that simulator and default facility graph distances agree. Independent random directed graphs include closure and disconnected cases; the oracle uses a different all-pairs algorithm. Queue tests compare forecast stock with actual stock, and predicted charging/arrival times with execution, within numerical precision. These checks establish reference geometry and software behavior; DOM fixtures and scene construction do not verify browser rendering, real-device gestures or GPU performance.

Not verified here: physical sensors/localization/clock synchronization, actual broker ACLs and receiver throughput for the new edge kit, AMR execution acknowledgments, LabVIEW override latency under prediction load, separate-host predictive deployment, independent ground truth and browser/GPU visual rendering. The ESP32 starter is unchanged; optional metadata is backward-compatible with v1 telemetry.

The final audit runs ten JavaScript suites and six standard-library Python unit tests. `node automated_tests/final_feature_alignment_checks.mjs` adds the cross-feature regressions listed above. Static checks verify unique HTML IDs, referenced assets, module syntax/imports, stylesheet parsing, Python syntax, both ZIP CRCs and exact member/source bytes. Tests are supplied in the source repository and edge unit tests in the edge download.
