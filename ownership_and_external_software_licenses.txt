This project is purely for educational purposes. Its original application
code, interface design and project content belong to S L RICHRIS.

The Simulation source uses virtual robots, telemetry, inventory and forecasts.
The optional Hardware workspace receives measurements from up to three ESP32
devices through a user-configured secure MQTT broker. The Live AMRs floor
source displays only fresh, measured poses in an illustrative warehouse.
No physical motor, mission or emergency-stop commands are transmitted.
This is an educational monitoring demonstration, not a robot-control system.
